## Declaração constitucional

Este documento constitui o instrumento oficial de validação da estrutura física, documental, hierárquica e editorial do repositório da camada de dados do Portal Permanente da FESTANÇA.

Seu propósito é verificar se os arquivos e diretórios fisicamente localizados no ciclo F3-P2 permanecem coerentes com:

- a arquitetura constitucional;
- o inventário documental;
- o padrão oficial de nomes;
- os caminhos aprovados;
- a estrutura Markdown;
- as denominações institucionais;
- as seções obrigatórias;
- as regras de versionamento;
- a compatibilidade com GitHub;
- a compatibilidade com Termux;
- a proteção integral da edição fundadora.

Nenhuma estrutura será considerada válida apenas porque o arquivo pode ser aberto.

Nenhum documento será considerado completo apenas porque possui conteúdo.

Nenhuma correção será realizada durante a primeira passagem de validação.

Nenhuma divergência será ocultada.

Nenhuma seção ausente será inserida silenciosamente.

Nenhum arquivo será movido, renomeado, substituído ou excluído sem análise de impacto, registro, aprovação e possibilidade de retorno.

A FESTANÇA 2026, como edição fundadora, deverá permanecer integralmente protegida durante todas as verificações estruturais.

- apresentar cabeçalho sem conteúdo;
- não possuir vigência;
- não possuir estado inicial;
- não possuir fechamento institucional.


# 43. Validação de arquivos vazios ou reduzidos

Deverão ser registrados:

- zero byte;
- uma única linha;
- título sem conteúdo;
- estrutura muito inferior à prevista;
- arquivo criado, mas não finalizado;
- conteúdo substituído por marcador;
- arquivo com texto de teste.

Comandos:

```bash
find docs/festanca/data -type f -size 0 -print
```

```bash
find docs/festanca/data -type f -name '*.md' -exec wc -l {} \; | sort -n
```
